# start_training_job

Call this only after you have the model, KPI, channels and date range from the user. The user approves, edits, or rejects the request first. After approval the job is queued and runs locally on the bundled sample MMM dataset. Tell the user to follow progress on the Jobs tab. If the request is invalid, ask the user to correct it.
