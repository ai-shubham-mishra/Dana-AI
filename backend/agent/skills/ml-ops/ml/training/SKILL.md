# Training

Confirm the KPI, channels and connector with the user, and resolve the date range with the calendar tools. Then draft the script with `create-training-script`, adjust it with `edit-training-script` if needed, and start it with `run-training-script`, which needs approval. Track progress with `check-job-status` and save outputs with `save-ml-assets`.
