# System operations

Use the tools in this domain to find the client's data, to ask the user for choices, and to work out dates and numbers. Connectors (`connectors/`) list what data is available. HITL (`hitl/`) asks the user when a choice is needed. Calendar (`calendar/`) resolves dates and holidays, so the user is not asked for them. Utilities (`utilities/`) performs exact calculations.
