# ask_user

Use this for each missing input (KPI, channels, date range, connector, currency). Ask one question at a time. Offer options when the answer comes from a known set.

The question is shown as Markdown. When you list several items (a plan, options, settings), use one Markdown bullet per line (`- Model: MMM`), not inline bullet characters.
