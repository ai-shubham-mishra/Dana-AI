# Calendar

Use these tools instead of asking the user for dates. Call `get_current_date` for today, then `resolve_date_range` for phrases such as "last 12 months" or "this year". Call `get_calendar_events` when a holiday or seasonal date may affect the data. Ask the user for a date only when these tools cannot resolve it.
